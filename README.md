# E-Commerce Health Check

## Project Overview

This project performs a health check of an online retail business using the Brazilian E-Commerce Public Dataset by Olist.

## Objectives

- Analyze top products by revenue
- Calculate repeat-customer rate
- Analyze monthly order trends
- Study order-value distribution
- Detect order-value outliers
- Analyze shipping time and customer review scores
- Calculate a 95% confidence interval for average order value
- Compare weekend and weekday order volume
